# Billie Eilish - Proyecto Web (DAM1M04)

## Descripción del proyecto
Este repositorio contiene el desarrollo de un sitio web dedicado a **Billie Eilish**, cantante y compositora estadounidense reconocida por su estilo musical único dentro del pop alternativo y el electropop.

La página web recoge su trayectoria artística, su discografía principal (*When We All Fall Asleep, Where Do We Go?*, *Happier Than Ever* y *Hit Me Hard and Soft*), sus premios más destacados y material multimedia relacionado con la artista.
